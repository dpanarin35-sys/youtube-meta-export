TERMS OF USE

Условия использования

Дата вступления в силу: 6 сентября 2026 г.

1. Назначение сервиса

YouTube Meta Exporter предоставляет пользователю инструмент для выгрузки данных принадлежащего ему или доступного ему YouTube-канала. Сервис использует YouTube API Services и не является продуктом YouTube или Google.

2. Учётная запись и разрешения

Вы входите через официальный OAuth Google и самостоятельно подтверждаете разрешения. Используйте сервис только для данных, к которым у вас есть законный доступ. Не передавайте свои OAuth-токены или скачанные данные третьим лицам без соответствующих прав.

3. YouTube API Services

Используя сервис, вы соглашаетесь соблюдать Условия использования YouTube. Сервис не загружает видео, не изменяет ролики, не обходит ограничения YouTube и не предназначен для скачивания видеоматериалов.

4. Субтитры и квоты

Загрузка текста субтитров выполняется только по выбору пользователя и может расходовать квоту YouTube API. Пользователь понимает, что отдельные дорожки могут быть недоступны из-за настроек ролика или разрешений YouTube.

5. Ограничение ответственности

Сервис предоставляется «как есть». Владелец приложения не настроен не гарантирует доступность YouTube API, полноту или неизменность возвращаемых YouTube данных.

6. Контакт
